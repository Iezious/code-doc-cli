## Definition of done

- `LANGUAGE` is a real `JavaScriptPlugin` instance.
- Chunk kinds: `"function"` (function declarations, arrow functions assigned at module scope, class methods), `"class"` (class declarations), `"module"` (top-level non-def/class statements not consumed by imports).
- Methods inside a class: `scope = "<ClassName>"`, `name = "<methodName>"`.
- Default export: synthetic symbol `name = "default::<file-stem>"` (where `<file-stem>` = `path.stem`). `kind = "def"`, `line` = line of the `export default` keyword.
- Named exports: `Symbol.name` is the export name as written.
- Imports:
  - `import x from "mod"` → `Edge(target="mod", kind="import", line=L, meta={"names": ["x"]})`.
  - `import { a, b } from "mod"` → one edge with `meta={"names": ["a", "b"]}`.
  - `import * as ns from "mod"` → `meta={"names": ["* as ns"]}`.
  - `import "mod"` (side-effect) → `meta={"names": []}`.
  - `require("mod")` at module scope → `meta={"names": [], "form": "require"}`.
- `uv run pytest tests/test_javascript_plugin.py` passes; `uv run pyright` and `uv run ruff check` pass.
