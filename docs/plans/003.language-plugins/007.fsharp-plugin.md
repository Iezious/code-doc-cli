## Signatures

```python
# src/code_index/languages/fsharp.py

from pathlib import Path
from .protocol import Chunk, Symbol, Edge

class FSharpPlugin:
    name = "fsharp"
    extensions = (".fs", ".fsi", ".fsx")

    def chunk(self, path: Path, content: str) -> list[Chunk]: ...
    def symbols(self, path: Path, content: str) -> list[Symbol]: ...
    def imports(self, path: Path, content: str) -> list[Edge]: ...

LANGUAGE = FSharpPlugin()
```

The plugin reads the project's `.fsproj` lazily by walking up from `path` to find a sibling or ancestor `*.fsproj`. The search is bounded — see [`007.context.md`](007.context.md). If found, parse the `<Compile Include="..." />` elements via `xml.etree.ElementTree` and produce an in-process cache mapping resolved file path → order index. The cache is keyed on the `.fsproj` path so different roots in the same process do not collide.

## Definition of done

- `LANGUAGE` is a real `FSharpPlugin` instance.
- Chunk kinds: `"function"` (`let` / `let rec` at module scope; `member` declarations), `"type"` (record, DU, class definitions; computation-expression builder types), `"module"` (file-scope `module X =` chunk), `"namespace"` (file-scope `namespace X` chunk). Order matters in F#; chunks are emitted in source order.
- The `.fsproj` order index is recorded somewhere on each chunk emitted from a file whose path resolves into the `.fsproj`'s `<Compile Include>` list. Storage form: the coder picks between (a) appending it to `scope` as `"Module|fsproj=3"` or (b) including it as a free-form suffix `"Module"` and recording it on a sibling structure. Whichever form is chosen, it is **consistent across chunks** and pinned by the snapshot. Document the choice in `outcome.md` if it surfaces architectural intent.
- Without a `.fsproj`: emit one stderr warning per parsed file via `write_log_stderr("warning: no .fsproj found for <path>; scope ordering may be wrong")`. Continue parsing.
- Symbols: module-qualified (e.g. `"Geometry.Point"`, `"Geometry.translate"`). Discriminated union cases as separate `def` symbols: `"Module.TypeName.CaseName"`.
- Imports: one `Edge` per `open` declaration. `target` is the opened path (`"System.IO"`). `kind = "import"`, `meta = None`.
- `uv run pytest tests/test_fsharp_plugin.py` passes (including both the with-`fsproj` and no-`fsproj` test paths).
- `uv run pyright` and `uv run ruff check` pass.
