# Step 002 — Python plugin

## Goal

Replace `src/code_index/languages/python.py`'s placeholder with a real plugin that chunks Python source via the stdlib `ast` module, emits dotted-scope symbols, and records `import` / `from ... import` statements as `import` edges. Lock behavior with a syrupy snapshot test.

## Files to create or modify

- `src/code_index/languages/python.py` (edit — replace placeholder body)
- `tests/test_python_plugin.py` (new)
- `tests/fixtures/languages/python/sample.py` (new)
- `tests/__snapshots__/test_python_plugin.ambr` (generated by `pytest --snapshot-update`, committed)

## Signatures

```python
# src/code_index/languages/python.py

from pathlib import Path
from .protocol import Chunk, Symbol, Edge

class PythonPlugin:
    name = "python"
    extensions = (".py",)

    def chunk(self, path: Path, content: str) -> list[Chunk]: ...
    def symbols(self, path: Path, content: str) -> list[Symbol]: ...
    def imports(self, path: Path, content: str) -> list[Edge]: ...

LANGUAGE = PythonPlugin()
```

## Definition of done

- `LANGUAGE` is a real `PythonPlugin` instance; the placeholder is gone.
- `chunk` emits one `Chunk` per `FunctionDef`, `AsyncFunctionDef`, and `ClassDef` plus one `module_body` chunk for top-level non-def/non-class statements (kind `"module"` per `chunking-and-languages.md`). Each chunk's `start_line` / `end_line` are 1-based and match the AST's `lineno` / `end_lineno`. `text` is the slice of source between those lines (1-based, inclusive on both ends).
- `name` field on chunks uses the bare identifier; `scope` is the dotted enclosing scope (`"Class"` for a method, `"Class.outer"` for a nested def, `None` for module-level definitions).
- `symbols` emits one `def` symbol per `FunctionDef`, `AsyncFunctionDef`, `ClassDef`; `name` is dotted from the module root within the file (matches `Module.Class.method` convention, but the "module" prefix is the file's stem; see step context). No `ref` symbols in this phase — leaves call-site harvesting for a later phase.
- `imports` emits one `Edge` per import statement; for `import x` the `target` is `"x"`; for `from a.b import c` the `target` is `"a.b.c"`. `kind = "import"`. `line` is the statement line. `meta` is `None`.
- Snapshot files committed under `tests/__snapshots__/test_python_plugin.ambr`.
- `uv run pytest tests/test_python_plugin.py` passes.
- `uv run pyright` and `uv run ruff check` pass.
