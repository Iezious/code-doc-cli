## Package extraction

`package_clause`'s identifier is the package name. The plugin reads it once per file and uses it as the prefix for every `Symbol.name`. The package name does NOT appear in `Chunk.name` (which stays the bare identifier) — it only appears in `Symbol.name` and at the head of `scope`.

## Node mapping

| Tree-sitter node                    | Chunk `kind`     | Notes                            |
|-------------------------------------|------------------|----------------------------------|
| `function_declaration`              | `"function"`     | top-level functions              |
| `method_declaration`                | `"function"`     | receiver recorded in scope       |
| `type_declaration`                  | `"type"`         | includes structs, interfaces, aliases |
| `var_declaration` at file scope     | `"module"`       | one chunk per block              |
| `const_declaration` at file scope   | `"module"`       | one chunk per block              |

Top-level `var x = ...` (without grouping) — emit one `"module"` chunk per declaration. Grouped `var ( ... )` — one chunk for the whole block.

## Receiver type extraction

A `method_declaration` has a `receiver` field, e.g. `(w *Widget)` or `(w Widget)`. Extract the type identifier, stripping any pointer asterisk. The method's `scope` is then `"<pkg>.<ReceiverType>"`, and `Symbol.name` is `"<pkg>.<ReceiverType>.<MethodName>"`.

## Imports — grouped vs single

```go
import "fmt"
import (
    f "fmt"
    _ "embed"
    . "errors"
    "io"
)
```

→ five edges total, one per imported path. Each edge's `line` is the line of *that path's* node (not the line of the `import` keyword for the group). `meta` is `dict | None`:

- No alias: `meta = None`.
- Alias present: `meta = {"alias": "<alias>"}` where `<alias>` is the raw token (`"f"`, `"_"`, `"."`).

## Symbol naming examples

```go
package widgets

type Frobnicator struct { ... }       // Symbol.name = "widgets.Frobnicator"
func New() *Frobnicator { ... }        // Symbol.name = "widgets.New"
func (f *Frobnicator) Run() { ... }    // Symbol.name = "widgets.Frobnicator.Run", scope = "widgets.Frobnicator"
```

## Error tolerance

Never raise. Tree-sitter's error recovery is good for Go; missing package clause → still emit chunks but use an empty-string package prefix (`Symbol.name` becomes just `"Frobnicator"` instead of `"widgets.Frobnicator"`). Snapshot pins the chosen behavior.
