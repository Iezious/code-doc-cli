## Signatures

```python
# src/code_index/languages/golang.py

from pathlib import Path
from .protocol import Chunk, Symbol, Edge

class GoPlugin:
    name = "go"
    extensions = (".go",)

    def chunk(self, path: Path, content: str) -> list[Chunk]: ...
    def symbols(self, path: Path, content: str) -> list[Symbol]: ...
    def imports(self, path: Path, content: str) -> list[Edge]: ...

LANGUAGE = GoPlugin()
```

Module filename is `golang.py` (avoids shadowing Python's `go` semantics); plugin `name` is `"go"` to match the architecture doc.

## Definition of done

- `LANGUAGE` is a real `GoPlugin` instance.
- Chunk kinds: `"function"` (function declarations + methods), `"type"` (type declarations including aliases and structs/interfaces), `"module"` for top-level `var`/`const` blocks plus the package clause. Each top-level `var (...)` or `const (...)` block is one chunk of kind `"module"` (separate chunks per block).
- Symbols: package-qualified. Top-level `func Foo` → `Symbol(name="<pkg>.Foo", kind="def", line=L)`. Method on `Widget` → `Symbol(name="<pkg>.Widget.Render", kind="def", line=L)` with `scope = "<pkg>.Widget"` recorded on the corresponding chunk.
- Imports: one `Edge` per imported path. `import "fmt"` → `target="fmt"`. `import f "fmt"` → `target="fmt"`, `meta={"alias": "f"}`. `import _ "fmt"` → `target="fmt"`, `meta={"alias": "_"}`. `import . "fmt"` → `target="fmt"`, `meta={"alias": "."}`. Each entry in a grouped `import (...)` block is its own edge with its own `line`.
- `uv run pytest tests/test_golang_plugin.py` passes; `uv run pyright` and `uv run ruff check` pass.
