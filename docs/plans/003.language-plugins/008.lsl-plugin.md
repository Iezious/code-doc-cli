# Step 008 — LSL plugin

## Goal

Replace `src/code_index/languages/lsl.py`'s placeholder with a real plugin that chunks LSL via a regex / hand-rolled state machine: state blocks, event handlers within states, global declarations, user functions; emits `ref` symbols for `llXxx` call sites; and records `listen` / `link_message` / `llHTTPRequest` / `llEmail` calls as edges of distinct kinds. Pure LSL only — no `osXxx` recognition. Lock behavior with a syrupy snapshot test. Phase 3 DoD also covers OSSL absence (see [`outcome.md`](outcome.md)).

## Definition of done

- `LANGUAGE` is a real `LSLPlugin` instance.
- Chunk kinds: `"state"` (state declaration spanning the whole `state X { ... }` block), `"event"` (event handler inside a state; `scope` = state name), `"function"` (user-defined function at global scope; `scope = "global"`), `"module"` (single chunk for global declarations — variable and constant decls at file scope, excluding states and functions).
- Symbols (`def`): user functions by bare name (`Symbol(name="foo", kind="def", line=L)`); event handlers as `"<state>.<event>"` (e.g. `"default.touch_start"`); global variables by bare name.
- Symbols (`ref`): every `llXxx` identifier that appears in a call position (followed by `(`) is one `ref` symbol per occurrence. Deduplication is NOT performed at the plugin level — Phase 4+ may dedupe at the indexer.
- Edges (per architecture):
  - `llListen(channel, ...)` → `Edge(target=<channel-literal-or-expr-text>, kind="listen", line=L, meta=None)`.
  - `llMessageLinked(link, number, str, key)` → `Edge(target=<number-arg-text>, kind="link_message", line=L, meta=None)`.
  - `llHTTPRequest(url, params, body)` → `Edge(target=<url-arg-text>, kind="http", line=L, meta=None)`.
  - `llEmail(to, subject, body)` → `Edge(target=<to-arg-text>, kind="email", line=L, meta=None)`.
  - `<arg-text>` is the literal source text of the relevant argument expression, verbatim and trimmed. If the argument is not a literal (e.g. a variable), the target is the variable name as written. Snapshot pins this.
- **OSSL absence:** no `osXxx` identifier appears in any returned `Symbol` or `Edge`. The plugin's regex set explicitly excludes the `os` prefix; the test pins this.
- `imports()` returns `[]` — LSL has no imports.
- `uv run pytest tests/test_lsl_plugin.py` passes.
- `uv run pyright` and `uv run ruff check` pass.
