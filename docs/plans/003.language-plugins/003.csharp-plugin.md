## Definition of done

- `LANGUAGE` is a real `CSharpPlugin` instance.
- Chunk kinds: `"class"`, `"struct"`, `"record"`, `"interface"`, `"enum"`, `"function"` (methods and local functions), `"module"` for any top-level statements at file scope. `name` is the bare identifier. `scope` is the namespace-qualified enclosing context (e.g. `"MyCorp.Widgets.Frobnicator"` for a method inside `class Frobnicator` inside `namespace MyCorp.Widgets`).
- Symbols: one `def` symbol per chunk that has a name, with `Symbol.name = "<Namespace>.<Type>.<Member>"` (matching `chunking-and-languages.md`'s convention "Namespace.Type.Member"). Generic type parameters stripped from `name`; if useful, recorded in `scope` — coder's call, but document the choice via the snapshot.
- Imports: one `Edge` per `using` directive. `target` is the dotted name (`"System"`, `"System.Collections.Generic"`). `using static System.Math` → `target="System.Math"`. `using X = System.IO.Path` (alias) → `target="System.IO.Path"` (alias dropped). `kind = "import"`, `meta = None`.
- Malformed input does not raise; plugin returns whatever tree-sitter recovers, or `[]`.
- `uv run pytest tests/test_csharp_plugin.py` passes; `uv run pyright` and `uv run ruff check` pass.
