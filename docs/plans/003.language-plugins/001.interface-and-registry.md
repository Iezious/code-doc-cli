# Step 001 — Plugin interface and registry

## Goal

Provide the shared `Chunk` / `Symbol` / `Edge` dataclasses, the runtime-checkable `Language` Protocol, and a `LanguageRegistry` that resolves extensions to plugins, loads `extra_languages` modules via `importlib.util`, and filters by `config.languages`. ## Signatures

```python
# src/code_index/languages/protocol.py

from dataclasses import dataclass
from pathlib import Path
from typing import Protocol, runtime_checkable

@dataclass(frozen=True)
class Chunk:
    start_line: int
    end_line: int
    kind: str              # "function" | "type" | "module" | "class" | "state" | "event" | ...
    name: str | None
    scope: str | None      # enclosing scope, e.g. "MyModule.SubModule" or "default" (LSL state)
    text: str

@dataclass(frozen=True)
class Symbol:
    name: str
    kind: str              # "def" | "ref"
    line: int

@dataclass(frozen=True)
class Edge:
    target: str            # symbol name or external identifier
    kind: str              # "import" | "call" | "listen" | "link_message" | "http" | ...
    line: int
    meta: dict[str, object] | None

@runtime_checkable
class Language(Protocol):
    name: str
    extensions: tuple[str, ...]

    def chunk(self, path: Path, content: str) -> list[Chunk]: ...
    def symbols(self, path: Path, content: str) -> list[Symbol]: ...
    def imports(self, path: Path, content: str) -> list[Edge]: ...
```

```python
# src/code_index/languages/registry.py

from pathlib import Path
from .protocol import Language

class LanguageRegistry:
    def __init__(self, plugins: list[Language]) -> None: ...

    def for_extension(self, ext: str) -> Language | None:
        """Resolve a file extension (".py", ".cs", ...) to a plugin, or None."""

    def names(self) -> list[str]:
        """Return the `name` of every registered plugin, in registration order."""

    @classmethod
    def from_builtins(cls) -> "LanguageRegistry":
        """Import every built-in plugin module and collect its LANGUAGE / LANGUAGES exports."""

    def with_extras(self, paths: list[Path]) -> "LanguageRegistry":
        """Return a new registry augmented with plugins loaded from extra-language module paths."""

    def filter_active(self, language_names: list[str] | None) -> "LanguageRegistry":
        """Return a new registry containing only plugins whose `name` is in `language_names`.
        If `language_names` is None, return self unchanged (no filtering)."""


def load_extra_language(path: Path) -> list[Language]:
    """Import `path` via importlib.util and return its LANGUAGE / LANGUAGES exports as a list.

    Raises:
        CodeIndexError(EXIT_CONFIG, Kinds.CONFIG_BAD_PATH, ...) if the file does not exist
            or cannot be loaded by importlib.
        CodeIndexError(EXIT_CONFIG, Kinds.CONFIG_UNKNOWN_LANGUAGE, ...) if the module
            exposes neither LANGUAGE nor LANGUAGES.
    """


def active_plugins(config) -> LanguageRegistry:
    """Build a registry from built-ins + config.extra_languages, then filter by config.languages.

    `config` is the resolved CodeIndexConfig from Phase 1. This is the single entry point
    Phase 4's indexer will call.
    """
```

## Tests

`tests/test_languages_registry.py`:

- `test_builtin_registry_resolves_every_extension` — parametrize over `(".py", "python")`, `(".cs", "csharp")`, `(".js", "javascript")`, `(".ts", "typescript")`, `(".go", "go")`, `(".fs", "fsharp")`, `(".fsi", "fsharp")`, `(".fsx", "fsharp")`, `(".lsl", "lsl")`. For each, `LanguageRegistry.from_builtins().for_extension(ext).name == expected_name`.
- `test_unknown_extension_returns_none` — `.for_extension(".xyz")` returns `None`.
- `test_runtime_checkable` — every built-in plugin satisfies `isinstance(plugin, Language)`.
- `test_load_extra_language_returns_list` — `load_extra_language(synthetic_path)` returns `[plugin]` where `plugin.name == "synthetic"` and `plugin.extensions == (".syn",)`.
- `test_with_extras_adds_extension` — `registry.with_extras([synthetic_path]).for_extension(".syn").name == "synthetic"`.
- `test_filter_active_keeps_listed_drops_others` — `from_builtins().filter_active(["python", "go"]).for_extension(".py")` is the Python plugin; `.for_extension(".cs")` is `None`.
- `test_filter_active_none_passes_through` — `.filter_active(None)` resolves every built-in extension.
- `test_load_extra_language_missing_file` — `load_extra_language(Path("/nonexistent/path.py"))` raises `CodeIndexError` with `code == EXIT_CONFIG` and `kind == Kinds.CONFIG_BAD_PATH`.
- `test_load_extra_language_missing_export` — point at a fixture file that defines no `LANGUAGE` and no `LANGUAGES` (inline-created via `tmp_path`); raises `CodeIndexError` with `kind == Kinds.CONFIG_UNKNOWN_LANGUAGE`.
- `test_load_extra_language_languages_tuple` — point at a fixture file that exports `LANGUAGES = (p1, p2)` (inline-created via `tmp_path`); returns both plugins.
- `test_active_plugins_end_to_end` — load `config_with_extra.toml` via the Phase 1 config loader (or build a `CodeIndexConfig` directly), call `active_plugins(config)`, assert `.for_extension(".syn").name == "synthetic"` and that the registered names are exactly `["synthetic"]` because the fixture's `languages` key filters built-ins out.

## Definition of done

- `src/code_index/languages/protocol.py` defines `Chunk`, `Symbol`, `Edge`, and the runtime-checkable `Language` Protocol with the exact field set and types in Signatures.
- `src/code_index/languages/registry.py` exposes `LanguageRegistry`, `load_extra_language`, and `active_plugins` with the documented behavior.
- Registry's `from_builtins()` imports every module under `src/code_index/languages/` whose name is one of the seven built-in plugin filenames and harvests `LANGUAGE` / `LANGUAGES`. The import list is hard-coded in `registry.py`; do not crawl the filesystem.
- `extra_languages` loading uses `importlib.util.spec_from_file_location` + `module_from_spec` + `loader.exec_module`. No `sys.path` mutation.
- `syrupy>=4` added to `[project.optional-dependencies].dev` in `pyproject.toml`; `uv sync --extra dev` resolves cleanly.
- All registry tests pass under `uv run pytest tests/test_languages_registry.py`.
- `uv run pyright` passes for the new files; the Protocol is `@runtime_checkable` and every built-in plugin asserts as a `Language` instance at test time.
- `uv run ruff check` passes.

In step 001 the seven plugin modules referenced by `from_builtins()` do not yet exist with real behavior — they exist only because step 001 must import them. To unblock 001 without depending on 002–008, step 001 creates each plugin module as a one-line skeleton with `LANGUAGE = _PlaceholderPlugin("python", (".py",))` (or similar) inside a private helper. Steps 002–008 replace the skeleton in their own module. See [`001.context.md`](001.context.md) for the placeholder shape.
