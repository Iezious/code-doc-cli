# Step 005 — TypeScript plugin

## Goal

Replace `src/code_index/languages/typescript.py`'s placeholder with a real plugin that chunks TypeScript via tree-sitter (TS grammar, separate from JS), emits export-name symbols including type-only exports, and records imports with type-only imports tagged in edge meta. Lock behavior with a syrupy snapshot test.

## Files to create or modify

- `src/code_index/languages/typescript.py` (edit — replace placeholder body)
- `tests/test_typescript_plugin.py` (new)
- `tests/fixtures/languages/typescript/sample.ts` (new)
- `tests/__snapshots__/test_typescript_plugin.ambr` (generated, committed)

## Signatures

```python
# src/code_index/languages/typescript.py

from pathlib import Path
from .protocol import Chunk, Symbol, Edge

class TypeScriptPlugin:
    name = "typescript"
    extensions = (".ts", ".tsx")

    def chunk(self, path: Path, content: str) -> list[Chunk]: ...
    def symbols(self, path: Path, content: str) -> list[Symbol]: ...
    def imports(self, path: Path, content: str) -> list[Edge]: ...

LANGUAGE = TypeScriptPlugin()
```

## Tests

`tests/test_typescript_plugin.py`:

- `test_extensions` — `LANGUAGE.extensions == (".ts", ".tsx")`.
- `test_name`, `test_runtime_checkable`.
- `test_chunk_snapshot`, `test_symbol_snapshot`, `test_import_snapshot` against `sample.ts`.
- `test_type_only_import_tagged` — fixture contains `import type { Foo } from "./types"`; assert the resulting edge has `meta["type_only"] is True`.
- `test_malformed_does_not_raise`.

Fixture `sample.ts` must exercise everything in JS plus: `interface`, `type` alias, `enum`, `namespace`, generic type alias (`type Box<T> = ...`), `import type { ... } from "..."`, and a type-only export. See [`005.context.md`](005.context.md) for the fixture outline.

## Definition of done

- `LANGUAGE` is a real `TypeScriptPlugin` instance.
- Chunk kinds: everything JS emits, plus `"interface"`, `"type"` (for `type` aliases), `"enum"`, `"namespace"`. Generic type parameters are stripped from `name`; `scope` mirrors the same handling decision the C# plugin makes.
- Symbols include type-only exports (`export type Foo = ...` → `Symbol(name="Foo", kind="def", line=L)`).
- Imports — same shape as JS plus `meta["type_only"] = True` for `import type ...` statements; absent or `False` otherwise. Coder picks "absent" vs "False"; snapshot pins the choice.
- `uv run pytest tests/test_typescript_plugin.py` passes; `uv run pyright` and `uv run ruff check` pass.
