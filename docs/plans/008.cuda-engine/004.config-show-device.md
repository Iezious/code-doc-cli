## Tests

In `tests/test_config_show.py`:

- Update `test_after_build_index_block_is_populated` (line ~126): the asserted `index` key set/ordering becomes `{schema_version, code_index_version, embed_model, embed_dim, embed_device}`.
- JSON output includes top-level `requested_device` and `effective_device` as siblings of `config` and `index` (not inside `config`).
- `requested_device` reflects `CODE_INDEX_DEVICE` (monkeypatched): `auto` when unset, and the set value otherwise; reported with NO probe (assert it is correct even when the probe is monkeypatched to raise).
- `effective_device` is the resolved value (`cpu`/`cuda`) using a quiet probe; assert no stderr warning is emitted even when `requested_device` is `cuda` and the probe reports CUDA unavailable (diagnostic stance — `warn=False`).
- `config show` exits 0 and does not raise when the onnxruntime probe raises (broken/missing provider) — `effective_device` falls back gracefully (resolves to `cpu`).
- `index.embed_device` is `null`/"" for an index built before this feature (no `embed_device` row); use the `_set_meta_direct` helper to construct the pre-feature case.
- Text format renders both new device fields.

## Definition of done

- `_INDEX_META_KEYS` includes `embed_device` as the final element; both JSON and text index blocks carry it; absent value renders as `null` (JSON) / "" (text) per existing meta handling.
- `requested_device` (via step 001 `requested_device()`, no probe) and `effective_device` (via step 001 `resolve_device(warn=False)`) appear as top-level siblings of `config` and `index` in the JSON document.
- Text renderer prints both device fields.
- `config show` never fails on a broken/missing onnxruntime probe and never emits a device warning (quiet `warn=False` resolution).
- The existing `[mismatch]` suffix remains scoped to `embed_model` only (device is not identity — no mismatch concept).
- Updated `test_config_show.py` ordering/key-set assertion passes; new device assertions pass; `uv run ruff check`, `uv run ruff format`, `uv run pyright` clean.
