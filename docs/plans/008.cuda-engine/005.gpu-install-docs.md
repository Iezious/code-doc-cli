# Step 005 — GPU install documentation

## Goal

Document the GPU acceleration install path in the README: the `fastembed-gpu` manual swap, setting `CODE_INDEX_DEVICE=cuda`, the `fastembed`/`fastembed-gpu` mutual exclusivity, and that `pyproject.toml` is intentionally unchanged.

## Files to create or modify

## Definition of done

- README install section gains a GPU acceleration subsection covering:
  - Base install keeps `fastembed` (CPU) as the default hard dependency; zero-config offline CPU is unchanged.
  - GPU path is a manual swap: `uv pip install fastembed-gpu` (replacing `fastembed`), then set `CODE_INDEX_DEVICE=cuda`.
  - `fastembed` and `fastembed-gpu` are mutually-exclusive PyPI dists sharing the `fastembed` import namespace and pulling mutually-exclusive onnxruntime builds — install one, never both.
  - There is intentionally NO `[gpu]` install extra (it cannot work cleanly); `pyproject.toml` is unchanged.
  - `CODE_INDEX_DEVICE` values: `auto` (default — CUDA if available else CPU, silent), `cuda` (warn + CPU fallback if unavailable), `cpu` (force CPU).
  - Note that `CODE_INDEX_DEVICE=cuda` on a box with only base `fastembed` falls back to CPU with a stderr warning (the provider is not registered).
- No `pyproject.toml` change is made.
- Wording does not contradict [embeddings.md](../../architecture/embeddings.md) "Update 2026-05-28: GPU acceleration".
