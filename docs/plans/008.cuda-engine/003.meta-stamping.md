# Step 003 — Stamp meta.embed_device at build

## Goal

Record the device the index was built on by stamping `meta.embed_device` alongside `embed_model`/`embed_dim` at build, and clear it on auto-rebuild.

## Files to create or modify

- `src/code_index/indexer.py` (modify — stamp + clear `embed_device`)
- `tests/test_indexer_pipeline.py` (modify — assert `embed_device` written)
- `tests/test_rebuild_cli.py` (modify — assert `embed_device` cleared/re-stamped on rebuild)

## Signatures

No new public signatures. The change is two edits inside existing functions:

```python
# indexer.py build(...) — alongside the existing stamp block:
        if not dry_run:
            set_meta(conn, "embed_model", backend.name)
            set_meta(conn, "embed_dim", str(backend.dim))
            set_meta(conn, "embed_device", backend.device)   # NEW
            conn.commit()

# indexer.py _auto_rebuild(...) — extend the DELETE key set:
        DELETE FROM meta WHERE key IN ('embed_model', 'embed_dim', 'embed_device')
```

## Tests

In `tests/test_indexer_pipeline.py` (exercises `build()`):

- After a non-dry-run build, `get_meta(conn, "embed_device")` equals the backend's resolved device (`cpu` in CI with no GPU).
- Under `--dry-run`, `embed_device` is NOT stamped (mirrors the existing dry-run handling of `embed_model`/`embed_dim`).

In `tests/test_rebuild_cli.py` (flows through `build()` via `_auto_rebuild`):

- After a rebuild over a populated index, `embed_device` is present and consistent with the backend (the DELETE then re-stamp leaves exactly one value, not a stale one).

## Definition of done

- `build()` stamps `meta.embed_device = backend.device` in the same non-dry-run block as `embed_model`/`embed_dim`, before the existing `conn.commit()`.
- `_auto_rebuild` DELETE clears `embed_device` along with `embed_model`/`embed_dim`.
- Dry-run does not stamp `embed_device`.
- `verify_index_compat` is NOT touched (device is not index identity — see [`context.md`](context.md)).
- `schema_version` is NOT bumped (additive `meta` KV key — see [`context.md`](context.md)).
- New/updated tests pass; `uv run ruff check`, `uv run ruff format`, `uv run pyright` clean.

## Dependencies
