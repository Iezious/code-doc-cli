# Step 002 — Factory

## Goal

Add `from_config(config) -> EmbeddingBackend`, the single dispatcher that turns a resolved `CodeIndexConfig` into a backend instance. `"fastembed"` returns a `FastembedBackend` built from `embed_model` and `embed_batch_size`; `"voyage"` raises `CodeIndexError` with `kind = "cli.not_implemented"` until Phase 7 lands the real implementation.

## Files

- `src/code_index/embeddings/factory.py` (new)
- `src/code_index/embeddings/__init__.py` (edit — re-export `from_config`)
- `tests/test_embedding_factory.py` (new)

## Signatures

```python
# src/code_index/embeddings/factory.py

from code_index.config import CodeIndexConfig
from code_index.errors import CodeIndexError, EXIT_USAGE, Kinds
from .protocol import EmbeddingBackend
from .fastembed import FastembedBackend


def from_config(config: CodeIndexConfig) -> EmbeddingBackend:
    """Instantiate the embedding backend specified by `config`.

    Reads `config.embed_backend`, `config.embed_model`, `config.embed_batch_size`.

    Returns:
        FastembedBackend when `embed_backend == "fastembed"`.

    Raises:
        CodeIndexError(EXIT_USAGE, Kinds.CLI_NOT_IMPLEMENTED, ...) when
        `embed_backend == "voyage"`. Phase 7 replaces this raise with the
        real Voyage backend.
    """
```

```python
from .protocol import EmbeddingBackend

```

## Tests

`tests/test_embedding_factory.py` — all factory tests mock `FastembedBackend` (no real downloads here; downloads are covered by step 001).

- `test_factory_dispatches_fastembed`: construct a `CodeIndexConfig` (via `load_config` against a fixture, or by direct Pydantic instantiation if test ergonomics call for it) with `embed_backend="fastembed"`, `embed_model="jinaai/jina-embeddings-v2-base-code"`, `embed_batch_size=32`. Monkeypatch `code_index.embeddings.factory.FastembedBackend` to a spy. Assert the spy is called once with positional/keyword args matching the config values; assert the return value of `from_config` is the spy's return value.
- `test_factory_passes_batch_size`: same as above but with `embed_batch_size=64`; assert the spy receives `batch_size=64`.
- `test_factory_passes_model`: with `embed_model="some-other-fastembed-model"`, assert the spy receives that exact model string.
- `test_factory_raises_for_voyage`: config with `embed_backend="voyage"` (and any compatible `embed_model`, e.g. `"voyage-code-3"`); assert `from_config(config)` raises `CodeIndexError`; assert `error.code == EXIT_USAGE`; assert `error.kind == Kinds.CLI_NOT_IMPLEMENTED`; assert `"Phase 7"` (or `"phase 7"`, case-insensitive) appears in `error.message`.
- `test_factory_voyage_message_mentions_voyage`: same setup; assert `"voyage"` appears in `error.message` (case-insensitive). This locks in the message being recognisable to a human reader.
- `test_init_reexports_from_config`: `from code_index.embeddings import from_config` succeeds.

## Definition of done

- `src/code_index/embeddings/factory.py` exists and exports `from_config`.
- `from_config` reads `embed_backend`, `embed_model`, `embed_batch_size` off the passed config and dispatches as specified.
- `"fastembed"` path constructs `FastembedBackend(model=embed_model, batch_size=embed_batch_size)`. (Cache dir is left at the library default; tests are the only consumer that overrides it.)
- `"voyage"` path raises `CodeIndexError(EXIT_USAGE, Kinds.CLI_NOT_IMPLEMENTED, ...)`. Message contains `"voyage"` and `"Phase 7"`.
- `code_index.embeddings.__init__` re-exports `from_config` alongside `EmbeddingBackend` and `FastembedBackend`.
- Factory tests run without performing any model download (verified by monkeypatching `FastembedBackend`).
- `uv run pytest tests/test_embedding_factory.py` passes.
- `uv run pyright` passes; `from_config`'s return type is `EmbeddingBackend`, and pyright validates that `FastembedBackend` is assignable to it.
- `uv run ruff check` passes.
- Phase 2 DoD from [`context.md`](context.md) is fully satisfied after this step.
