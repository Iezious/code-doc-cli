# Step 001 — Package skeleton

## Goal

Create the `code_index` Python package and wire up `pyproject.toml` so that `uv sync --extra dev`, `uv run pyright`, and `python -m code_index` all work, even though no real CLI commands are implemented yet.

## Files to create or modify

- `src/code_index/__init__.py` (new)
- `src/code_index/__main__.py` (new)
- `pyproject.toml` (edit)
- `pyrightconfig.json` (new, optional — equivalent `[tool.pyright]` in `pyproject.toml` is acceptable)
- `tests/__init__.py` (new, empty)
- `tests/test_package_skeleton.py` (new)

`pyproject.toml` requirements (additive — must not remove existing keys established in `2a84281`):

- `[project].dependencies` contains `pydantic>=2`, `typer>=0.12`, `sqlite-vec>=0.1`.
- `[project.optional-dependencies].dev` contains `pytest`, `ruff`, `pyright>=1.1.350`.
- `[project.optional-dependencies].voyage` exists (may be empty list `[]` or a placeholder dependency the architect's `embeddings.md` will pin in Phase 2; leave it declared either way).
- `[project.scripts]` declares `code_index = "code_index.cli:app"`.
- `[tool.pyright]` (or `pyrightconfig.json`): `include = ["src/code_index"]`, strict mode on `src/`, basic on `tests/`.

## Tests

`tests/test_package_skeleton.py`:

- `test_version_is_str`: `code_index.__version__` is a non-empty string.
- `test_module_main_invokes_cli`: invoking `python -m code_index --help` (via `subprocess.run` or by importing `code_index.__main__` after step 005 lands) exits 0 once step 005 is complete. For this step in isolation, assert the module imports without error. The coder may mark the full subprocess assertion `@pytest.mark.xfail(strict=False, reason="cli implemented in step 005")` or skip it entirely; either is fine.

## Definition of done

- `uv sync --extra dev` resolves without conflict.
- `uv run pyright` runs (it may emit no errors because the package is nearly empty; that is acceptable).
- `uv run ruff check` passes.
- `uv run pytest tests/test_package_skeleton.py` passes.
- `code_index.__version__` returns a string.
- `pyproject.toml` declares `code_index = "code_index.cli:app"` under `[project.scripts]`.
- `pyproject.toml` declares `pydantic>=2`, `typer>=0.12`, `sqlite-vec>=0.1` under base dependencies.
- `pyproject.toml` declares `pyright>=1.1.350` under the `dev` extra.
- The `[voyage]` install extra is declared.
- Pyright configuration is in place (either `[tool.pyright]` or `pyrightconfig.json`).
