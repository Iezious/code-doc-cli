# Step 004 — context

## Authoritative source

[`../../architecture/storage.md`](../../architecture/storage.md) — schema sketch, indices, schema_version semantics, WAL mode, sqlite-vec, FTS5, migrations directive.

## Schema_version is a string

`storage.md` does not pin the type, but [`context.md`](context.md) decision 2 settles it as the string `"1"`. Persisted as TEXT in `meta.value`. All comparisons use string equality.

## Migrations are the only schema writer

There is no "create schema from scratch" code path that bypasses migrations. The first migration `0_to_1.py` IS the schema-from-scratch path. A future `1_to_2.py` would be a delta. Treat the migrations directory as the single source of truth for schema.

## What `0_to_1.py` creates

Six tables: `meta`, `files`, `chunks`, `chunks_fts` (FTS5 virtual), `embeddings` (vec0 virtual), `symbols`, `edges` — plus the named indices on `chunks(path)`, `chunks(language)`, `symbols(name)`, `edges(dst_name)`, `edges(src_chunk_id)`. The `files(path TEXT PRIMARY KEY, mtime REAL, size INTEGER)` table is part of schema v1 per the 2026-05-19 sync-mechanism revision in `storage.md`; Phase 1 creates it empty and Phase 4's indexer populates it. There is no `1_to_2.py` migration to add it later.

## Embedding dim choice

`vec0` requires a concrete dim at table-creation time. Phase 1 does not embed anything, but the table must exist for storage tests to pass. Use `768` (fastembed Jina v2 base code dim, also the default backend per [`../../architecture/embeddings.md`](../../architecture/embeddings.md) — referenced indirectly through [`../../architecture/mvp-scope.md`](../../architecture/mvp-scope.md)). This decision is local to step 004 — Phase 2 owns any change.

## sqlite-vec load

`sqlite-vec` distributes a loadable extension. Typical Python usage:

```python
import sqlite_vec
conn.enable_load_extension(True)
sqlite_vec.load(conn)
conn.enable_load_extension(False)
```

If the import or `load(conn)` fails for any reason, translate to `CodeIndexError(EXIT_INDEX_SCHEMA, Kinds.INDEX_VEC_EXTENSION_UNAVAILABLE, ...)` with the underlying exception text in `detail["cause"]`.

## FTS5 availability probe

The cheapest probe: `SELECT sqlite_compileoption_used('ENABLE_FTS5')`. If it returns 0, raise `Kinds.INDEX_FTS5_UNAVAILABLE`. The architecture doc does not pin a probe — this is an implementation choice; document it in the helper's docstring.

## Migration file naming

`<from>_to_<to>.py`. Both are integer strings. Discovery uses `pkgutil.iter_modules` (or `importlib.resources.files(__package__).iterdir()`) and parses the filename. Files whose names do not match the pattern are ignored. `__init__.py` is excluded.

## Concurrency note (informational)

WAL mode is enabled per connection. The storage module does not yet implement the "single writer, many readers" pattern from `storage.md` — that lands when the indexer arrives in Phase 4. Phase 1 only opens one connection at a time in tests.

## Test fixture path

Storage tests use `tmp_path` from pytest; no fixture files needed.
