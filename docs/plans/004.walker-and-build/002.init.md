# Step 002 — init subcommand

## Goal

Replace the Phase 1 `code_index init` stub with a real implementation that
writes `docs/.helpers/config.toml` and `docs/.helpers/.gitignore`. Idempotent,
with `--force` to overwrite an existing config.

## Files

- `src/code_index/cli.py` (edit — replace the `init` stub)
- `src/code_index/init.py` (optional new helper module if the body grows
  past ~30 lines; the coder's call)
- `tests/test_cli_init.py` (new)

## Signatures

```python
# src/code_index/cli.py
@app.command()
def init(
    name: str | None = None,
    force: bool = False,
) -> None: ...
```

If a helper module is introduced:

```python
# src/code_index/init.py
from pathlib import Path

def write_skeleton(
    project_root: Path,
    *,
    project_name: str | None,
    force: bool,
) -> None:
    """Write docs/.helpers/config.toml and docs/.helpers/.gitignore under
    project_root. Refuses to overwrite an existing config.toml unless
    force=True. Re-writes an identical .gitignore as a no-op."""
```

## Tests

`tests/test_cli_init.py` uses `typer.testing.CliRunner` against `tmp_path`:

- **Fresh init.** `runner.invoke(app, ["init"])` against an empty
  `tmp_path` (with CWD or equivalent set to `tmp_path`) creates
  `docs/.helpers/config.toml` and `docs/.helpers/.gitignore`. Assert the
  files exist and contain the expected keys (`version`, `project`,
  `roots`, `embed_backend`, `embed_model` in the TOML; `index.sqlite`,
  `index.sqlite-wal`, `index.sqlite-shm` in the gitignore).
- **Refuses overwrite.** Second `init` against the populated dir returns
  a non-zero exit code with a clear stderr message. Stdout is empty.
- **`--force` overwrites.** `runner.invoke(app, ["init", "--force"])`
  against the populated dir succeeds.
- **`--name`.** `runner.invoke(app, ["init", "--name", "custom-name"])`
  produces a config whose `project` value is `"custom-name"`.
- **`.gitignore` idempotency.** `--force` against a populated dir where
  the `.gitignore` is identical to what we would write does not error
  even though `config.toml` was overwritten.

The directory the CLI treats as "project root" (the parent of
`docs/.helpers/`) is the current working directory. Tests change CWD to
`tmp_path` via `monkeypatch.chdir(tmp_path)` before invoking the runner.

## Definition of done

- All five `tests/test_cli_init.py` cases pass.
- `code_index init` against an empty directory produces a config that the
  Phase 1 config loader accepts without error (a smoke assertion in the
  first test: load the written file and confirm no exception).
- The written config matches the "What `init` writes" section of
  `docs/architecture/config.md`. `version` is pinned to a PEP 440 range
  computed from the running engine version (e.g. `">=0.3,<0.5"` if the
  engine is `0.3.x` or `0.4.x`).
- The written `.gitignore` contains the three lines `index.sqlite`,
  `index.sqlite-wal`, `index.sqlite-shm`, one per line, trailing newline.
- `uv run pytest tests/test_cli_init.py` passes.
- `uv run ruff check src/code_index/cli.py tests/test_cli_init.py`
  passes (plus `src/code_index/init.py` if it exists).
- `uv run pyright` passes for the touched files.
