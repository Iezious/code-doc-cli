# Step 003 — indexer pipeline

## Goal

Implement `src/code_index/indexer.py`: the pipeline that composes the walker
(step 001), the Phase 3 language plugins, the Phase 2 embedding backend, and
the Phase 1 storage layer into one `build(...)` call. Plugin raises and
per-file IO errors skip + warn; the build completes and returns a summary.

## Files

- `src/code_index/indexer.py` (new)
- `tests/test_indexer_pipeline.py` (new)

## Signatures

```python
# src/code_index/indexer.py
from dataclasses import dataclass
from pathlib import Path

@dataclass
class IndexerResult:
    files_walked: int
    files_chunked: int
    chunks_inserted: int
    symbols_inserted: int
    edges_inserted: int
    seconds_elapsed: float

def build(
    config,
    root: Path,
    *,
    dry_run: bool = False,
    verbose: bool = False,
) -> IndexerResult:
    """Build the index for `root` using `config`.

    Auto-rebuild: if the index already contains rows, the row data is
    silently cleared from chunks / chunks_fts / embeddings / symbols /
    edges / files, and the indexer-owned meta keys are reset, before
    insert. meta.schema_version is preserved.

    Writes to: chunks, chunks_fts, embeddings, symbols, edges, files,
    and the indexer-owned meta keys (embed_model, embed_dim).

    Plugin raises and per-file IO errors: skip + warn on stderr,
    continue, do not raise.

    Infrastructure failures (storage open fails, backend init fails)
    raise CodeIndexError with the appropriate code/kind.
    """
```

## Tests

`tests/test_indexer_pipeline.py` uses mocked plugins (canned `Chunk` /
`Symbol` / `Edge` lists), a mocked `EmbeddingBackend` returning deterministic
float vectors of dimension 768, and a real on-disk SQLite database at
`tmp_path / "docs/.helpers/index.sqlite"` opened via the Phase 1 storage
helper. Cases:

- **Fresh DB, happy path.** Two mock plugins (`.py` and `.foo`), each
  yielding two `Chunk`s, one `Symbol` per chunk, one `Edge` per chunk.
  Fixture tree has two files. Result counts match: `files_walked=2`,
  `files_chunked=2`, `chunks_inserted=4`, `symbols_inserted=4`,
  `edges_inserted=4`. `meta.embed_model` and `meta.embed_dim` are
  written. Querying `chunks_fts` for a token from a chunk returns it.
- **`files` table populated.** Same two-file fixture as the happy path:
  after `build` returns, `SELECT COUNT(*) FROM files` equals 2 (one row
  per successfully chunked file). For each file the stored `path` uses
  forward slashes and matches the `chunks.path` value written for that
  file; `mtime` equals `os.stat(absolute_path).st_mtime` (use
  `pytest.approx` for float comparison); `size` equals the on-disk byte
  length. A file whose plugin raises (see the "Plugin raise" case
  below) does NOT get a `files` row.
- **Pre-populated DB (auto-rebuild).** Run `build` once, then run
  `build` again with a different fixture set. Prior rows are dropped
  from all six row-data tables (including `files`); final counts
  reflect only the second run.
- **`dry_run=True`.** Walker runs, chunker runs, but the mocked
  backend's `encode` is never called and no rows land in `chunks` or
  `embeddings`. `IndexerResult` reports the walk/chunk counts but
  `chunks_inserted == 0`. The `files` table is also untouched in
  dry-run.
- **Plugin raise.** One mock plugin raises on a specific filename;
  build still completes; a warning lands on stderr (captured via
  `capsys`); the failing file's rows are absent from `chunks`,
  `symbols`, `edges`, AND `files`; other files are indexed normally.
- **Per-file IO error.** A file becomes unreadable mid-walk (simulate
  by patching the walker's read path or by handing the indexer a
  pre-built `WalkedFile` list with one entry whose `content` raises on
  access — coder's call). Build still completes; warning emitted;
  no `files` row for the failing file; other files indexed.
- **Empty input.** A root with no matching files yields an
  `IndexerResult` with all counts zero; `backend.encode` is never
  called (empty-batch no-op); `files` table is empty.
- **Embedding batching.** With `embed_batch_size=2` and four chunks,
  `backend.encode` is called exactly twice with two texts each.

## Definition of done

- All eight `tests/test_indexer_pipeline.py` cases pass.
- The indexer writes to `chunks`, `chunks_fts`, `embeddings`,
  `symbols`, `edges`, `files`, and updates `meta.embed_model` /
  `meta.embed_dim`.
- For every file successfully chunked, a row is upserted into `files`:
  `path` is `walked_file.rel_path` rendered with forward slashes
  (consistent with `chunks.path`), `mtime` is `os.stat(path).st_mtime`,
  `size` is the on-disk byte size. Files that fail (plugin raise,
  per-file IO error) do not get a `files` row. The polyglot DoD test
  in step 004 will assert `files` row count equals the number of
  successfully chunked files.
- Auto-rebuild path clears row data from the six indexer-owned tables
  (`chunks`, `chunks_fts`, `embeddings`, `symbols`, `edges`, `files`)
  before insert when any of them is non-empty. `meta.schema_version`
  is untouched.
- Plugin raises and per-file IO errors do not abort the build.
- `uv run pytest tests/test_indexer_pipeline.py` passes.
- `uv run ruff check src/code_index/indexer.py
  tests/test_indexer_pipeline.py` passes.
- `uv run pyright src/code_index/indexer.py` passes.
