# Step 001 — walker

## Goal

Implement `src/code_index/walker.py`: a file walker that yields `WalkedFile`
records for every file under a root that should be indexed, honoring every
rule in `architecture.md`'s "Indexer walking" section.

## Files

- `src/code_index/walker.py` (new)
- `pyproject.toml` (edit — add `pathspec>=0.12` to `[project.dependencies]`)
- `tests/test_walker.py` (new)
- `tests/fixtures/walker/` (new — multiple small subdirectories, one per rule)

## Signatures

```python
# src/code_index/walker.py
from dataclasses import dataclass
from pathlib import Path
from typing import Iterator

@dataclass(frozen=True)
class WalkedFile:
    path: Path                # absolute
    rel_path: Path            # relative to walk root
    content: str              # UTF-8 decoded; replacement chars on decode error
    extension: str            # ".py", ".cs", ...
    decode_warning: bool      # True if replace-fallback was used

def walk(root: Path, config) -> Iterator[WalkedFile]:
    """Yield WalkedFile records for every file under `root` that should be
    indexed. Honors .gitignore (when root has .git), default built-in
    excludes, max file size, NUL-byte binary detection, symlink policy,
    UTF-8 + replace fallback."""
```

The `config` argument is the Phase 1 config object. The walker reads
`config.ignores` (additive patterns), `config.languages` (to derive the set
of plugin-registered extensions via the Phase 3 `active_plugins(config)`
registry), and nothing else. The walker does not itself import plugin
modules; it asks the registry for `extensions_for_active_languages()` or an
equivalent existing method on the registry.

## Tests

`tests/test_walker.py` exercises each rule with a small fixture directory
under `tests/fixtures/walker/`:

- `.gitignore` honored when `.git/` directory is present at the root; not
  honored when absent. Use nested `.gitignore` as well as root-level.
- Built-in default excludes always applied (`node_modules/`, `.venv/`,
  `__pycache__/`, `.git/`, `dist/`, `build/`, `.idea/`, `.vscode/`,
  `docs/.helpers/`). At least one positive case (file under such a dir is
  not yielded).
- `config.ignores` patterns merged with the defaults (additive — defaults
  still apply).
- Max file size: a file above the 1 MiB cap is skipped with a stderr
  warning; the walker yields nothing for it.
- NUL-byte detection: a file with a plugin-registered extension but with a
  NUL byte in the first 8 KiB is skipped. A file without a
  plugin-registered extension is skipped regardless of NUL state.
- Symlinks: file symlink is followed (yielded once, with the link path);
  directory symlink is not followed; missing symlink target warns on stderr
  and is skipped.
- Encoding: a file containing non-UTF-8 bytes is yielded with
  `decode_warning=True`; a stderr warning is emitted.

Fixtures may be generated on the fly per test where that is simpler than
checking in binary content (binary files, broken symlinks). Where files are
checked in, they live under `tests/fixtures/walker/<rule-name>/`.

## Definition of done

- `walk(root, config)` yields exactly the expected set of `WalkedFile`
  records for each fixture in `tests/fixtures/walker/`.
- Stderr warnings are emitted via the Phase 1 errors module helper (no
  bare `print(..., file=sys.stderr)`).
- `pathspec>=0.12` is in `[project.dependencies]` and `uv sync --extra dev`
  succeeds.
- `uv run pytest tests/test_walker.py` passes.
- `uv run ruff check src/code_index/walker.py tests/test_walker.py`
  passes.
- `uv run pyright src/code_index/walker.py` passes.

## Dependencies

- Phase 1 (errors module for stderr warning helper, config object shape).
- Phase 3 (registry method that exposes the set of extensions for the
  active language plugins). The walker does not need plugin instances, only
  the extension set. See [`001.context.md`](001.context.md) for the exact
  registry call to use.

No dependency on Phase 2 or on later steps in this feature.
