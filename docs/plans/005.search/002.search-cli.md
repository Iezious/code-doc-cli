# Step 002 — `search` CLI and end-to-end DoD

## Goal

Replace the Phase 1 `code_index search` stub with the real implementation:
parse all flags from `cli.md`, validate `--lang` against the registry,
open the index, run `search(...)` from step 001, format results as either
text stanzas (default) or a single JSON document (`--format json`), and
prove the whole phase against the Phase 4 polyglot fixture. This step
owns the Phase 5 DoD.

## Files

- `src/code_index/cli.py` (edit — replace the `search` stub)
- `tests/test_search_cli.py` (new)

The polyglot fixture is reused from
`tests/fixtures/projects/polyglot_minimal/`, owned by Phase 4 step 004.

## Signatures

```python
# src/code_index/cli.py

@app.command("search")
def cli_search(
    ctx: typer.Context,
    query: str = typer.Argument(...),
    lang: str | None = typer.Option(None, "--lang"),
    k: int = typer.Option(20, "--k", min=1),
    bm25_k: int = typer.Option(100, "--bm25-k", min=1),
    dense_k: int = typer.Option(100, "--dense-k", min=1),
    kind: str | None = typer.Option(None, "--kind"),
    path: str | None = typer.Option(None, "--path"),
    mode: str = typer.Option("hybrid", "--mode", help="bm25|dense|hybrid"),
) -> None: ...
```

`--format`, `--config`, `--verbose`, `--quiet` come from the shared app
callback (Phase 1); `cli_search` reads them off `ctx.obj`.

The function:

1. Validates `mode in {"bm25", "dense", "hybrid"}`; otherwise raises
   `CodeIndexError(EXIT_USAGE, "cli.bad_enum", ...)`. (Reuses the
   Phase 1 `Kinds.CONFIG_BAD_ENUM` is acceptable; coder may add a new
   `cli.bad_enum` if preferred — see [`002.context.md`](002.context.md)
   for the reuse-vs-add decision.)
2. Discovers the config (`ctx.obj["config"]` or the Phase 1
   `discover_config_path` walk from CWD). Missing config raises
   `CodeIndexError(EXIT_INDEX_MISSING, Kinds.INDEX_MISSING, ...)` with
   a pointer to `code_index init`.
3. Loads the config via `load_config(path)`.
4. Validates `--lang`: if non-None, must be in
   `active_plugins(config).names()`; otherwise raises
   `CodeIndexError(EXIT_CONFIG, Kinds.CONFIG_UNKNOWN_LANGUAGE, ...)`.
5. Resolves the DB path: `<project_root>/docs/.helpers/index.sqlite`.
   If the file does not exist, raises
   `CodeIndexError(EXIT_INDEX_MISSING, Kinds.INDEX_MISSING, "no index
   found; run `code_index index build`")`.
6. Opens the index: `conn = open_index(db_path, create_if_missing=False,
   check_version=True)`.
7. Instantiates the backend only when `mode != "bm25"`:
   `backend = embeddings.from_config(config)`. Calls
   `storage.verify_index_compat(conn, backend)`. On mismatch the
   `CodeIndexError` propagates to the Phase 1 boundary handler.
8. Calls `search.search(conn, query, backend=backend, mode=mode, k=k,
   bm25_k=bm25_k, dense_k=dense_k,
   filters=SearchFilters(lang=lang, kind=kind, path_glob=path))`.
9. Formats and writes the results to stdout:
   - `--format text`: one stanza per result. Stanza shape:
     ```
     <path>:<start_line>-<end_line>  [<language>] <kind> <name or "">
       <scope or "">                # only if scope is non-None
       <excerpt indented two spaces, preserving line breaks>
     ```
     Stanzas separated by a single blank line. Under `--verbose`,
     append a `  score=<float>` line after the header.
     Zero results: nothing on stdout (per `cli.md` and `retrieval.md`).
   - `--format json`: one document `{"results": [<row>, ...]}` where
     each row is the `SearchResult` dataclass fields verbatim
     (`path`, `start_line`, `end_line`, `language`, `kind`, `name`,
     `scope`, `excerpt`, `score`). Pretty-printing is the coder's
     choice; the document must round-trip through `json.loads`.
     Zero results: `{"results": []}`.
10. Exits 0. `CodeIndexError` is caught by the Phase 1 boundary
    handler and routed through `write_error_envelope_stdout` (under
    `--format json`) or `write_error_summary_stderr` (under
    `--format text`).

## Tests

`tests/test_search_cli.py` uses `typer.testing.CliRunner` and a
session-scoped fixture that builds the polyglot index once.

Fixture builder (`@pytest.fixture(scope="session")`):

- Copy `tests/fixtures/projects/polyglot_minimal/` to a session
  `tmp_path_factory`.
- `monkeypatch.chdir` into it (function-scoped wrapper around the
  session dir).
- Run `code_index init` via `CliRunner`.
- Run `code_index index build` via `CliRunner`.
- Return the project directory.

Tests (each `monkeypatch.chdir` into the session-built project):

- **DoD: known symbol-name query.** Pick a function name that appears
  exactly in one fixture source (e.g. a Python `def search_me`).
  Run `code_index search "search_me"`. Exit 0. Stdout contains a
  stanza whose header is `<expected_path>:<expected_start>-<expected_end>`.
  Choose names that are unique across the fixture corpus.
- **DoD: known conceptual query.** Place a docstring or comment in
  one fixture source with a clear conceptual phrase (e.g. "handle
  dropped websocket sessions"). Run `code_index search "websocket
  reconnection on drop"`. Exit 0. Top result is the chunk containing
  that docstring. The fixture sources may need a small augmentation
  in this step — see [`002.context.md`](002.context.md).
- **DoD: `--mode bm25`.** Run `code_index search "search_me" --mode
  bm25 --format json`. Stdout JSON has `results` list whose top item
  is the same chunk. Verify backend is not loaded by patching
  `embeddings.from_config` to raise; the test still passes (proves
  bm25 mode does not instantiate the backend).
- **DoD: `--mode dense`.** Run `code_index search "websocket
  reconnection on drop" --mode dense --format json`. Stdout JSON
  parses; `results` is non-empty.
- **DoD: `--mode hybrid` matches default.** Run the same query with
  `--mode hybrid` and without `--mode`; result lists are identical
  (assert by chunk-id order and length).
- **`--format json` shape.** Run any query with `--format json`;
  `json.loads(stdout)` produces `{"results": [{...}]}` and each row
  has all nine `SearchResult` fields.
- **Zero results, text mode.** Run `code_index search
  "definitely_not_in_the_fixture_xyzzy"`. Exit 0; stdout is empty;
  stderr may contain a progress line under default verbosity but
  no error summary.
- **Zero results, JSON mode.** Same query with `--format json`.
  Exit 0; stdout is exactly `{"results": []}` (after `json.loads`).
- **`--lang python` filter.** Run a query that would match both
  Python and JS chunks; with `--lang python`, every result has
  `language == "python"`.
- **`--lang invalid` rejection.** Run `code_index search "x" --lang
  fortran`. Exit 2; under `--format json`, envelope `kind ==
  "config.unknown_language"`.
- **`--kind function` filter.** Same shape as `--lang`.
- **`--path "**/main.py"` filter.** Glob match; results' paths
  satisfy the glob.
- **No index found.** From a `tmp_path` with no `docs/.helpers/`,
  run `code_index search "x"`. Exit 12; envelope `kind ==
  "index.missing"`; message mentions `code_index init`.
- **Index built with wrong model — drift error.** Take the session
  project, overwrite `meta.embed_model` to `"voyage:code-3"` via
  raw SQL, then run `code_index search "x" --mode hybrid`. Exit 11;
  envelope `kind == "index.embed_model_mismatch"`; message mentions
  `code_index index rebuild`. Restore the meta row after the test
  (or use a function-scoped copy of the session project).
- **`--bm25-k 0` rejection.** Typer's `min=1` rejects this at parse
  time; exit code 2 (Typer's default for usage error) is acceptable
  — does not need to round-trip through `CodeIndexError`. Document
  this in [`002.context.md`](002.context.md).

The fastembed model cache from Phase 2's `tests/.cache/fastembed/`
is reused. CI cold run downloads ~120 MB on first execution; the
session fixture amortizes the cost across every test in this file.

## Definition of done

- All `tests/test_search_cli.py` cases pass.
- `code_index search "<query>"` against the polyglot fixture returns
  expected hits for both a symbol-name query and a conceptual query.
- `--mode bm25` and `--mode dense` each return single-pool result
  lists; `--mode hybrid` (default) returns the fused list.
- `--format json` emits `{"results": [...]}` for success and
  `{"results": []}` for zero-result; both round-trip through
  `json.loads`.
- `--lang` is validated against the active language registry;
  unknown values exit 2 with `kind == "config.unknown_language"`.
- Missing index exits 12 with `kind == "index.missing"`.
- Embedding model drift exits 11 with
  `kind == "index.embed_model_mismatch"`; dim drift exits 11 with
  `kind == "index.embed_dim_mismatch"`.
- Stream discipline: results on stdout, logs/warnings on stderr.
  `--quiet` does not change stdout.
- `uv run pytest` passes for the whole suite (this step plus step
  001 plus all prior phases already passing).
- `uv run ruff check` passes.
- `uv run pyright` passes.
