# Step 001 — `config show` full body

## Goal

Replace Phase 1's `config show` stub-shape body with the full diagnostic implementation: read `meta.schema_version`, `meta.code_index_version`, `meta.embed_model`, `meta.embed_dim`, print them as a sibling `"index"` block to the existing `"config"` block under `--format json` (text mode: aligned `key: value` lines), and never raise on missing or mismatched index.

## Files to create or modify

- `src/code_index/cli.py` (edit — replace `cli_config_show` body)
- `tests/test_config_show.py` (new)

## Signatures

```python
# src/code_index/cli.py

@config_app.command("show")
def cli_config_show(ctx: typer.Context) -> None: ...
```

Internal helper (lives in `cli.py`; may be promoted to `code_index.storage` if step 003/004 also need it, but Phase 7 does not require that):

```python
def _read_index_meta(db_path: pathlib.Path) -> dict[str, str] | None:
    """Open the index in diagnostic mode (no schema-version check) and return
    a dict with keys 'schema_version', 'code_index_version', 'embed_model',
    'embed_dim'. Returns None if db_path does not exist. Raises CodeIndexError
    with Kinds.INDEX_UNREADABLE if the file exists but cannot be opened as a
    SQLite database."""
```

`cli_config_show` behavior:

1. Resolve the config path: `ctx.obj["config"]` if set, else `discover_config_path(Path.cwd())`. If neither yields a path, raise `CodeIndexError(EXIT_INDEX_MISSING, Kinds.INDEX_MISSING, "no docs/.helpers/config.toml found; run `code_index init`")`. Mirrors Phase 1's behavior.
2. Call `load_config(config_path)`. On `CodeIndexError`, re-raise (boundary handler routes).
3. Compute `db_path = config.project_root / "docs" / ".helpers" / "index.sqlite"` (or equivalent — match what `cli_init` and `cli_index_build` write to).
4. Call `_read_index_meta(db_path)`. Get either a dict of four string values or `None`.
5. Compose the output payload:
   - Under `--format text`: print the resolved config as `key: value` lines (sorted by key), a blank line, then `index:` followed by either `not built` or four indented `key: value` lines for the meta block. If the configured `embed_model` differs from `index.embed_model`, append ` [mismatch]` on the relevant line (text mode only). Stream via `write_result_stdout`.
   - Under `--format json`: emit a single JSON document `{"config": {...}, "index": <meta-dict-or-null>}`. Use `json.dumps(payload, indent=2, sort_keys=False)`; the `config` block keys appear in the order Phase 1 pinned (`005.context.md` lines 53–69). Stream via `write_result_stdout`.
6. Exit 0. Always exit 0 unless one of the three escape-hatch raises fired above (config not found / config invalid / index unreadable).

## Tests

`tests/test_config_show.py` uses `typer.testing.CliRunner` against `tmp_path`. Fixtures reuse `tests/fixtures/config_valid.toml` (Phase 1) and the polyglot fixture at `tests/fixtures/projects/polyglot_minimal/` (Phase 4). All test cases:

- **Fresh init, no index yet.** `runner.invoke(app, ["init"])` then `runner.invoke(app, ["config", "show", "--format", "json"])`. Exit 0. `json.loads(stdout)` returns `{"config": {...}, "index": null}`. `stderr` is empty.
- **After build.** Run `init` + `index build`. Run `config show --format json`. Exit 0. `json.loads(stdout)` returns a dict where `index` is a dict with keys `{"schema_version", "code_index_version", "embed_model", "embed_dim"}` and each value is a non-empty string.
- **Model mismatch.** After build, manually mutate `meta.embed_model` to `"wrong:model"` via `sqlite3` direct UPDATE. Run `config show --format json`. Exit 0. `json.loads(stdout)["config"]["embed_model"]` is the configured value; `json.loads(stdout)["index"]["embed_model"]` is `"wrong:model"`. Both are emitted; no error envelope.
- **Schema mismatch (diagnostic carve-out).** After build, mutate `meta.schema_version` to `"99"`. Run `config show --format json`. Exit 0. `json.loads(stdout)["index"]["schema_version"]` is `"99"`. **No error envelope.** This is the carve-out that distinguishes `config show` from every other subcommand.
- **Text mode.** Run `config show` (no `--format`). Exit 0. Stdout contains `key: value` lines including `embed_model: ...` from both blocks; the `index` section header appears; when index is absent, the line reads `index: not built`. Stderr is empty.
- **Config not found.** Run `config show` in a `tmp_path` with no `docs/.helpers/` discovered. Exit code `12` (`EXIT_INDEX_MISSING`). Under `--format json`, envelope `code == 12` and `kind == "index.missing"`.
- **Index unreadable.** Run `init`, then overwrite `docs/.helpers/index.sqlite` with non-SQLite bytes (e.g. `b"not a sqlite file"`). Run `config show --format json`. Exit code `10` (`EXIT_INDEX_SCHEMA`). Envelope `kind == "index.unreadable"`. (Distinct from the no-raise mismatch cases above — this is genuinely unparseable, not just mismatched.)
- **Stream discipline.** `config show --format json` on the happy path puts the JSON on stdout and nothing on stderr.
- **`json.loads` round-trip on every success path.** The five success-case tests above all parse stdout via `json.loads` without raising.

## Definition of done

- `config show` emits the JSON shape pinned in `context.md` decision 4 on every success path.
- `config show` never raises on missing index, schema mismatch, model mismatch, or dim mismatch — exits 0 with the diagnostic data.
- `config show` raises with the correct `code` / `kind` on: config not found, config validation failure, index file unreadable.
- Text mode emits aligned `key: value` lines and the `index: not built` line when absent.
- All cases in `tests/test_config_show.py` pass.
- `uv run pytest tests/test_config_show.py` passes.
- `uv run ruff check src/code_index/cli.py tests/test_config_show.py` passes.
- `uv run pyright` passes.
