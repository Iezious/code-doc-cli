# Step 002 — `init` JSON output shape

## Goal

Pin the `code_index init` JSON output shape (currently unpinned anywhere — Phase 4 emitted text-mode output only). Add a `--format json` branch to `cli_init` that emits a single JSON document carrying the four fields decided in `context.md` decision 3.

## Files to create or modify

- `src/code_index/cli.py` (edit — add JSON branch to `cli_init`)
- `tests/test_init_json.py` (new)

## Signatures

```python
# src/code_index/cli.py — body of cli_init is extended (signature unchanged)

@app.command()
def cli_init(
    ctx: typer.Context,
    name: str | None = typer.Option(None, "--name"),
    force: bool = typer.Option(False, "--force"),
) -> None: ...
```

`cli_init` JSON branch:

1. Phase 4's body already computes `config_path`, `gitignore_path`, project name, and whether an existing file was overwritten (the `--force` path). Lift those into local variables (named to match the JSON keys below).
2. Track `force_used`: `True` iff `--force` was passed **and** an existing `config.toml` was overwritten. `False` otherwise (fresh init; or `--force` against an empty dir).
3. After successful writes:
   - Under `--format text`: keep Phase 4's existing text-mode output unchanged. This step does not redesign the text mode.
   - Under `--format json`: emit `{"config_path": "<abs>", "gitignore_path": "<abs>", "project": "<name>", "force_used": <bool>}` via `write_result_stdout(json.dumps(payload, indent=2))`. Suppress the text-mode stdout / stderr summary lines under `--format json`.
4. On the refuse-without-`--force` path (Phase 4's behavior — config already exists, `--force` not passed): `CodeIndexError` is raised with the existing kind Phase 4 chose. Boundary handler routes; the envelope is on stdout under `--format json`, summary on stderr under `--format text`. No change to this path.

## Tests

`tests/test_init_json.py` uses `typer.testing.CliRunner` against `tmp_path` with `monkeypatch.chdir(tmp_path)`. Cases:

- **Fresh init, JSON mode.** `runner.invoke(app, ["init", "--format", "json"])`. Exit 0. `json.loads(stdout)` returns a dict with keys `{"config_path", "gitignore_path", "project", "force_used"}`. `config_path` is an absolute path string ending with `docs/.helpers/config.toml` (forward slashes). `gitignore_path` ends with `docs/.helpers/.gitignore`. `project` matches the directory name of `tmp_path`. `force_used` is `False`. Stderr is empty (no progress messages under JSON mode).
- **`--name` propagates.** `runner.invoke(app, ["init", "--format", "json", "--name", "custom-name"])`. `json.loads(stdout)["project"] == "custom-name"`.
- **`--force` against a populated dir.** Run `init` once, then `runner.invoke(app, ["init", "--format", "json", "--force"])`. Exit 0. `json.loads(stdout)["force_used"] == True`.
- **`--force` against an empty dir.** Run `init --force` first (no prior file). Exit 0. `force_used == False` (no file was overwritten; the flag was passed but did nothing).
- **Refuse without `--force`.** Run `init` once, then `runner.invoke(app, ["init", "--format", "json"])` (no force). Non-zero exit code (whatever Phase 4 pinned). `json.loads(stdout)` returns a dict with key `"error"` and `error.code` / `error.kind` matching Phase 4's choice. (This test asserts the envelope round-trips through `json.loads`; it does not assert which kind Phase 4 used — that is Phase 4's contract.)
- **Text mode unchanged.** `runner.invoke(app, ["init"])` (no `--format`). Phase 4's existing text-mode stdout is emitted unchanged. The presence of the JSON branch does not regress text mode.

## Definition of done

- `code_index init --format json` emits the four-key JSON document on success.
- `force_used` correctly distinguishes "overwrote an existing file" from "fresh init or no-op `--force`".
- Refuse-without-`--force` path emits an error envelope under `--format json` that round-trips through `json.loads`.
- Text-mode output is unchanged from Phase 4.
- All cases in `tests/test_init_json.py` pass.
- `uv run pytest tests/test_init_json.py` passes.
- `uv run ruff check src/code_index/cli.py tests/test_init_json.py` passes.
- `uv run pyright` passes.
