# Step 003 — symbols module and CLI

## Goal

Implement the `symbols` query layer at `src/code_index/symbols.py` and replace the `symbols defs` / `symbols refs` CLI stubs with thin wrappers that run the standard pre-flight check, call the query layer, and emit results.

## Signatures

```python
# src/code_index/symbols.py
from dataclasses import dataclass
import sqlite3

@dataclass(frozen=True)
class SymbolHit:
    path: str
    scope: str | None
    language: str
    name: str
    line: int

def query_symbols(
    conn: sqlite3.Connection,
    name: str,
    *,
    kind: str,                  # "def" or "ref"
    exact: bool = False,
    language: str | None = None,
) -> list[SymbolHit]:
    """Run the symbols defs|refs query against the index.

    Matching: case-sensitive. `exact=False` → SQL `LIKE '%name%'`.
    `exact=True` → SQL exact equality.
    """
```

```python
# src/code_index/cli.py — replaces the existing stubs
@symbols_app.command("defs")

    ctx: typer.Context,
    name: str,
    exact: bool = typer.Option(False, "--exact"),
    lang: str | None = typer.Option(None, "--lang"),
) -> None: ...

@symbols_app.command("refs")
def cli_symbols_refs(
    ctx: typer.Context,
    name: str,
    exact: bool = typer.Option(False, "--exact"),
    lang: str | None = typer.Option(None, "--lang"),
) -> None: ...
```

CLI wrapper behavior (shared between `defs` and `refs`):

1. Run the standard Phase 6 pre-flight check (see `context.md` "Cross-cutting constraints").
2. Call `query_symbols(conn, name, kind="def"|"ref", exact=exact, language=lang)`.
3. Emit results:
   - `--format text`: one line per hit. Suggested format: `<path>:<line> <language> <scope or "-"> <name>`. Empty result set emits nothing (and exit 0 — empty results are not a failure per `cli.md`).
   - `--format json`: a JSON array on stdout. Each element matches the `symbols defs|refs` shape pinned in `context.md` ("JSON output shapes"). Empty result emits `[]`.

## Tests

`tests/test_symbols_query.py` exercises `query_symbols(...)` directly against a hand-populated SQLite DB (open via `open_index`, insert canned `chunks` + `symbols` rows). No plugins, no embeddings — pure SQL test.

Cases:

- **Substring match.** Insert symbols `foo`, `foobar`, `barfoo`, `baz` (all kind=`def`). Query `name="foo"`, `exact=False` returns the first three; `query_symbols(name="baz")` returns the last.
- **Exact match.** Same fixture; `query_symbols(name="foo", exact=True)` returns only the `foo` row, not `foobar` / `barfoo`.
- **Case sensitivity.** Insert symbols `Foo` and `foo`. `query_symbols(name="foo", exact=True)` returns only `foo`; `query_symbols(name="Foo", exact=True)` returns only `Foo`. Substring is also case-sensitive: `query_symbols(name="oo")` returns both, `query_symbols(name="OO")` returns neither.
- **Language filter.** Insert chunks of languages `python` and `csharp` with overlapping symbol names. `query_symbols(name="X", language="python")` returns only the python rows.
- **`kind=def` vs `kind=ref`.** Insert one `def` and one `ref` row with the same name. Each kind returns only its own row.
- **Scope is surfaced.** Insert a chunk with `scope = "MyModule.MyClass"`; the matching symbol's hit has the same `scope`. A chunk with `scope = NULL` produces `SymbolHit.scope is None`.
- **Empty result.** Query against an empty DB returns `[]`, not an error.
- **Sort order.** Two hits in the same path: `query_symbols` returns them sorted by `(path, line)`.

`tests/test_symbols_cli.py`:

- **Missing index** — exit 12, `kind="index.missing"`.
- **Embed model mismatch** — exit 11, `kind="index.embed_model_mismatch"`.
- **JSON shape.** Run `code_index symbols defs Foo --format json` against a built fixture. `json.loads(stdout)` is a list of objects with exactly the keys `{path, scope, language, name, line}`.
- **Text shape.** Same query under default format; assert one line per hit.
- **Empty result.** Query an obviously-absent name (e.g. `--exact zzzz_not_present_zzzz`); exit 0; under `--format json`, stdout is `[]`; under text, stdout is empty.

## Definition of done

- `query_symbols(...)` returns `SymbolHit` rows matching the SQL contract in `context.md` ("Symbols / graph SQL contract").
- Substring is the default; `--exact` switches to exact match; case-sensitivity is preserved for both modes.
- `--lang` filter narrows results to one language.
- `scope` is surfaced from the `chunks` join.
- `--format json` matches the shape pinned in `context.md`.
- Empty result returns exit 0 with empty array / empty stdout, not an error.
- All seven `tests/test_symbols_query.py` cases pass and all five `tests/test_symbols_cli.py` cases pass.
- `uv run ruff check src/code_index/symbols.py src/code_index/cli.py tests/test_symbols_query.py tests/test_symbols_cli.py` passes.
- `uv run pyright src/code_index/symbols.py` passes.
