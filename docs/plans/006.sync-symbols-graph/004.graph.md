## Signatures

```python
# src/code_index/graph.py
from dataclasses import dataclass
import sqlite3

@dataclass(frozen=True)
class CallerHit:
    path: str
    scope: str | None
    language: str
    start_line: int
    kind: str
    dst_name: str

@dataclass(frozen=True)
class DepHit:
    path: str
    kind: str
    dst_name: str
    meta: str | None    # raw JSON string from edges.meta, or None

def query_callers(
    conn: sqlite3.Connection,
    symbol: str,
    *,
    exact: bool = False,
    language: str | None = None,
) -> list[CallerHit]:
    """Match edges.dst_name against `symbol`. Substring by default; --exact
    switches to equality. Case-sensitive. Returns source chunks."""

def query_deps(
    conn: sqlite3.Connection,
    path: str,
    *,
    language: str | None = None,
) -> list[DepHit]:
    """Return all edges whose src_chunk_id belongs to a chunk with chunks.path
    matching `path` exactly (decision 4). Includes unresolved dst_name values."""
```

```python
    ctx: typer.Context,
    symbol: str,
    exact: bool = typer.Option(False, "--exact"),
    lang: str | None = typer.Option(None, "--lang"),
) -> None: ...

@graph_app.command("deps")
def cli_graph_deps(
    ctx: typer.Context,
    path: str,
    lang: str | None = typer.Option(None, "--lang"),
) -> None: ...
```

CLI wrapper behavior:

- Both subcommands run the standard Phase 6 pre-flight check.
- `graph callers`: call `query_callers(conn, symbol, exact=exact, language=lang)`.
- `graph deps`: call `query_deps(conn, path, language=lang)`. Path is exact (decision 4) — no `--exact` flag on `deps`.
- Emit results:
  - `--format text`: one line per hit. Callers: `<path>:<start_line> [<language>] -> <dst_name> (<kind>) (scope: <scope>)`. Deps: `<path> -> <dst_name> (<kind>)`.
  - `--format json`: JSON array matching the shapes in `context.md` ("JSON output shapes").
  - Empty result: exit 0, `[]` under JSON, empty stdout under text.

## Tests

`tests/test_graph_query.py` works against a hand-populated SQLite DB:

- **Callers substring.** Insert chunks for files `a.py` and `b.py`, each with edges whose `dst_name` includes `"foo"` (e.g. `foo`, `foobar`). `query_callers(symbol="foo")` returns all matching source chunks.
- **Callers exact.** Same fixture; `query_callers(symbol="foo", exact=True)` returns only the `foo` rows.
- **Callers case-sensitive.** Insert `Foo` and `foo`. Each exact query returns only its own row; substring is also case-sensitive.
- **Callers lang filter.** Edges from chunks of mixed language; filter by `language="python"`.
- **Deps exact path match.** Insert chunks for `src/a.py` and `src/b.py`, each with two edges. `query_deps(path="src/a.py")` returns only `a.py`'s edges.
- **Deps no globbing.** `query_deps(path="src/a*")` returns `[]` (asterisk is not a wildcard).
- **Deps no substring.** `query_deps(path="a.py")` returns `[]` (must match `src/a.py` exactly).
- **Deps with unresolved `dst_name`.** Insert an edge whose `dst_name` does not correspond to any `symbols.name` row. `query_deps` still returns it; the contract allows unresolved targets.
- **Deps with `meta`.** Insert an edge with `meta = '{"channel": 42}'`. The returned `DepHit.meta` equals that raw string.
- **Deps with `meta = NULL`.** `DepHit.meta is None`.
- **Sort order.** Multiple hits sorted by `(path, start_line)` for callers and `(path, kind, dst_name)` for deps.

`tests/test_graph_cli.py`:

- **Missing index** — exit 12, `kind="index.missing"`.
- **Embed model mismatch** — exit 11, `kind="index.embed_model_mismatch"`.
- **JSON shape (callers).** Run `code_index graph callers Foo --format json` against a built fixture; `json.loads(stdout)` is a list of objects with exactly the keys `{path, scope, language, start_line, kind, dst_name}`.
- **JSON shape (deps).** Run `code_index graph deps src/main.py --format json` against a built fixture; `json.loads(stdout)` is a list of objects with exactly the keys `{path, kind, dst_name, meta}`.
- **Text shape.** Same queries under default format.
- **Empty result.** Both subcommands against absent symbols / paths return exit 0 with `[]` / empty stdout.

## Definition of done

- `query_callers(...)` and `query_deps(...)` return rows matching the SQL contract in `context.md` ("Symbols / graph SQL contract").

- Unresolved `dst_name` values are included in `deps` results.
- `meta` is surfaced as the raw JSON string from the column (or `None`).
- `--lang` filter narrows by `chunks.language`.
- `--format json` matches the shapes in `context.md`.
- All `tests/test_graph_query.py` cases pass and all `tests/test_graph_cli.py` cases pass.
